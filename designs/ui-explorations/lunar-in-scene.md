# 月亮融入原画

本轮仅调整夜航的月相构图与绘制方式，不改动原背景图或已安装程序。上一版四套设计稿保留。

## 可比较方向

- 原画融月：可见月面约 92 px，低对比淡墨纹理，暗部透出原来的天空，较柔和的边缘与下缘空气遮挡。
- 明月入景：可见月面约 109 px，亮面更容易感知；沿用相同的原画色调与光路。
- 上一版对照：保留约 140 px 的写实月面，方便直接比较。

两版新月亮的中心横坐标均约为画面宽度的 74%，对齐原背景的亮谷与水面反光。取消旧的独立短倒影和圆形光晕，不再让月亮像一个前景按钮。月相仍按任务进度变化，准确数字通过悬停、聚焦或点击查看。

月面现在使用可编程的低频颜料纹理与柔化相位遮罩，不再绘制陨石坑或不透明黑色半球。薄雾层复用原画相同位置的像素，在月亮下缘作轻微遮挡；它不是另外生成的云朵。过渡结束后停止逐帧绘制。

原计划通过内置图像生成制作透明手绘月面，但生成请求出现网络错误，没有获得可用的新素材。本稿改用代码原生月相图形完成，不声称新增了生成式月面图片；原背景素材保持不变。

## 验证

已检查 1024、736、320 像素宽度的三种设计，均无控件越界；宽屏高度统一为 928 px，窄屏为 1220 px。检查了悬停数字、暂停恢复、运行期设置只读、过渡结束停止绘制和减少动态效果。查看了月缺与满月截图，未以静态满月替代可交互进度。

本轮未测量 Windows 原生实现的 CPU、GPU 或功耗。
