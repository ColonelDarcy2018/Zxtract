# Zxtract：三套 UI 设计方向

这是设计探索，不是已安装应用的截图。界面内容为演示数据，所有操作只改变本地预览状态，不读取或修改压缩文件、剪贴板、注册表或密码库。应用源码和当前系统默认程序均未修改。

## 三套方向

| 方向 | 视觉与布局 | 进度设计 | 更适合 |
| --- | --- | --- | --- |
| [墨流 / INK FLOW](previews/ink-1400.png) | 墨黑、青绿与蓝紫墨彩；顶部操作区，左侧任务列表，右侧聚焦详情 | 清晰数值＋青绿到蓝紫的渐变条；批次使用一项一格的状态条 | 主品牌界面，有辨识度，兼顾夜间使用与细节查看 |
| [纸境 / PAPER STUDIO](previews/paper-1400.png) | 暖纸色、海松绿、衬线标题；左侧导航，宽任务列表，选中详情置底 | 细线进度，不发光；状态用文字、色条和排版区分 | 偏好安静、明亮、长时间使用的用户 |
| [栅格 / GRID ENGINE](previews/grid-1400.png) | 炭灰与黄绿；短标题、直角模块、等宽数据，底部检查与事件区 | 分段刻度条；处理中任务格用斜纹，错误用暖橙色和文字 | 批量处理、频繁查看阶段与日志的用户 |

建议以「墨流」作为主方向，保留「纸境」作为未来明亮主题候选。「栅格」的状态分段和日志布局可借鉴，但不建议将全部文案变成英文终端术语。三套不只是换配色：分别采用聚焦详情、编辑式宽列表和仪器式检查区。

## 核心体验约定

- 批次状态与单项进度分开。演示中完成 1/6 项不代表已处理 16.7% 的字节量；任务格按列表顺序显示，每格是一项任务。
- 密码验证没有可测量百分比时，显示「正在验证候选密码」，不放虚假的 0% 或装饰性进度。
- 炫彩只用于边缘纹理和有效进度。列表文字不压在墨彩图案上，操作按钮下有实色底。
- 选中行使用整行底色与左侧标记；筛选后详情同步到仍可见的任务。搜索无结果时不保留过期详情。
- 错误使用明确的「解压失败」和原因，操作直接进入候选密码面板；输入为空时给予反馈，关闭面板恢复焦点。
- 「暂停调度」准确表达当前实现：停止启动新任务，已在进行的解压继续。不会把活跃任务错误地画成全部静止。
- 取消需要确认；已完成输出保留。演示中的取消不会操作真实文件。
- 复制按钮短暂显示「已复制」，然后恢复原按钮；在预览中只模拟反馈，未写入系统剪贴板。
- 搜索、状态筛选、文件/文件夹切换、选中、密码面板、选项面板、日志和取消均可交互。文件选择、导出、打开目录、管理密码等系统动作仅提示演示，不假装已经实现系统操作。

## 动效与落地建议

当前稿采用静态墨彩和状态变化反馈，不持续播放背景动画。建议落地时使用 120–180ms 的按钮反馈和 200ms 左右的真实进度插值；不对百分比自动计时增长，不做整屏粒子、扫描线或频繁闪光。减少动态效果偏好下关闭过渡；状态仍用文字完整表达。

墨彩是轻量 JPEG 预览纹理，原始 PNG 保留在 `assets/ink-wash.png`。界面布局、文字、按钮和数据均为原生可编辑内容，不是 AI 生成的一整张界面位图。WPF 落地时可复用纹理、渐变画刷、样式触发器和现有进度绑定；水墨纹理与控件要分层，保留 `Mode=OneWay`。

此稿为了审阅所有内容而展开完整任务列表。实际桌面窗口需在固定高度内让任务列表滚动；窄窗口将墨流右侧详情转为底部区域，栅格日志可折叠。此轮验证是宽度重排，不是已验证 WPF 在 1024×640 下的实现。

## 成果与验证

- 可切换交互源：`zxtract-directions.html`，在本线程预览中查看。
- 三套主稿：`previews/ink-1400.png`、`paper-1400.png`、`grid-1400.png`。
- 1024 / 736 / 320 宽度检查图，以及墨流暂停和密码重试图，均在 `previews/`。
- 本地渲染与回归脚本：`verify-designs.cjs`；执行记录：`validation.json`。
- 三套的选择、筛选、全路径搜索、复制反馈、暂停、密码重试、面板互斥、取消确认和焦点检查通过；未检测到 JavaScript 运行错误。
- 正文、文件路径、状态和按钮文字的抽测最低对比度：墨流 6.14:1、纸境 4.74:1、栅格 5.73:1；四种宽度均无横向控件溢出。并非完整无障碍合规认证。
- 尊重减少动态效果偏好；预览没有联网数据请求和真实解压操作。

设计遵循了 [Fluent 的结构、焦点与对比度指导](https://fluent2.microsoft.design/accessibility)、[功能性动效指导](https://fluent2.microsoft.design/motion)，以及 [Carbon 对不确定进度和错误说明的要求](https://www.carbondesignsystem.com/building-blocks/core/components/progress-bar/accessibility)。配色、布局和推荐为本项目的设计判断，不是这些来源对本稿的背书。

## 自动续跑

本任务配置了当前线程每 5 小时续跑的 heartbeat `zxtract-ui`。续跑用于完成尚未交付的工作，不等于绕过账户额度或本机可用性限制。交付并验证完成后，Goal 标记完成，自动续跑暂停，避免重复生成同一成果。未来需要继续探索时可要求恢复并给出新的完成条件。
