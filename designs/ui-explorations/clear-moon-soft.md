# 晴空月相：去光圈与自然暗面

## 本轮范围

只修改可交互设计预览与版本化素材，不替换已安装程序、不修改原生应用代码、不提交已有工作区修改。保留上一版以便比较。

## 原因与调整

- 旧版的整圈亮晕来自原画自带月晕，以及在月球半径 1.13–1.235 倍范围渐隐的合成环带。两者叠加后，细月牙周围仍有完整圆形轮廓。
- 旧暗面使用天空线性亮度的 0.66 倍，会比天空更暗，形成清晰的黑圆盘；月体不透明并不等于视觉自然。
- 使用 imagegen 内置编辑生成[无月晕底图](assets/lunar-v8/night-clear-plate.png)，[完整提示词与来源](assets/lunar-v8/prompts.md)已留档。山水构图保持同一方向，原画月纹理继续复用。
- 月球只在自身轮廓内绘制，边缘仅做亚像素抗锯齿。不画外圈、不做外发光，满月时也不切回带光晕的整张原图。
- 暗面以天空的前景大气亮度近似衔接，只留极弱地照。月体内部保持不透明，降低的是明暗对比，而非把月球设为透明。
- 保留球面受光计算、连续渐盈/完整盈缺、暂停/重播、月相切换、整月悬停、键盘访问和减少动态设置。

## 科学边界

这是面向水墨界面的视觉近似，不是天文级辐射传输仿真。未计算真实日期、观测地、天平动、真实地照强度或天气。暗面不必总是完全不可见：细月牙时，地球反射的阳光可使暗面隐约可见，见 [NASA Earthshine](https://science.nasa.gov/moon/moon-phases/#h-earthshine)。为了减少可辨的黑色圆盘，本设计把地照处理得很弱。
