# 夜航月相内界精修 · v4

## 本轮范围

用户同意继续精修月牙内侧明暗交界。本轮只更新设计预览和说明，不修改正式应用，不替换系统安装，不提交 Git。未生成或修改位图素材，沿用 v3 原画。

四套主题与布局保留。夜航原生设计调整项“月色融合方式”新增“自然柔界”并设为默认；“薄雾融月”为上一版对照，旧版对照与柔光去边继续可用。

## 设计与实现

- 原画纹理、月亮比例和外圈去边处理不变。
- 自然柔界仅调整月相内侧透明遮罩，增加轻微的稳定起伏和不均匀柔化。
- 明暗边界变化按高度固定，不使用随机数或时间噪声；运动时不会出现噪点闪烁。
- 效果在上下月尖以及接近新月、满月时收敛，保留月相辨识度。
- 满月复用上一版渲染路径；0 与未知进度仍无月面残留。
- 缓存行级参数与遮罩缓冲区；只在月相变化时有限时长绘制，稳态不运行 Canvas RAF 循环。
- 其他主题未启用新遮罩。
