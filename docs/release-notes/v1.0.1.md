# Zxtract 1.0.1

许可与发布包修正版 / License and packaging maintenance release.

## 变更

- Zxtract 自有代码和资源正式采用 MIT License。
- 新增第三方组件声明，并完整收录 7-Zip 25.01 官方许可文本。
- 正式包现在明确包含 `7z.exe` 和 `7z.dll`，避免单文件发布模式将其隐藏在应用包内而导致运行时无法定位。
- 正式包包含 `LICENSE.txt`、`THIRD-PARTY-NOTICES.md` 和 `licenses/7-Zip-License.txt`。
- 发布脚本增加必要文件校验，缺少引擎或许可文件时停止生成压缩包。
- Release 构建不再携带调试符号。

## Changes

- Licensed Zxtract's original code and assets under the MIT License.
- Added third-party notices and the complete upstream 7-Zip 25.01 license text.
- Kept `7z.exe` and `7z.dll` as explicit files in the portable package so the application can locate the extraction engine reliably.
- Added `LICENSE.txt`, `THIRD-PARTY-NOTICES.md`, and `licenses/7-Zip-License.txt` to the package.
- Added release-package validation for the engine and required license files.
- Removed debug symbols from Release packages.
