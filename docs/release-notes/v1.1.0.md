# Zxtract 1.1.0

即时换肤、四套月相界面与更简洁的解压工作台 / Instant skin switching, four moon scenes, and a simpler extraction workbench.

本说明覆盖正式版本 [v1.0.2](https://github.com/ColonelDarcy2018/Zxtract/releases/tag/v1.0.2) 到 v1.1.0 的全部更新。1.0.2 已发布的文件夹闪退修复、列表去重和搜索改进不重复计为本版新增。

## 中文说明

### 功能与操作体验

- 新增即时换肤和偏好恢复：内置墨流、清简、夜航、月白、流萤、玄石六套皮肤；主窗口、密码助手、下拉项、日志和相关面板同步更新，无需重启。
- 外观和版本说明收进最小化按钮左侧的齿轮菜单；切换主题后自动关闭菜单，正在运行的任务、选中项和队列保留。
- 月相界面将页签、主状态与操作融入场景，移除重复的聚焦详情栏、外置批次状态条和设置工具栏。墨流、清简保留原工作台布局。
- 解压设置摘要直接显示输出、密码来源、同名策略、并行数及文件夹选项；详细设置改用居中弹窗。运行或暂停期间只读，空闲时修改仍使用原业务绑定；支持 Escape 关闭及焦点恢复。
- 每个文件保留实际解压百分比和细进度条，另有轻量运行转环。密码验证、分卷整理和输出提交等无可测量进度的阶段不显示假百分比；重试、打开位置和更多操作复用原命令。
- 暂停按钮明确标注“暂停调度 / 继续调度”：不再启动新任务，已开始的解压仍继续完成。

### 新外观与动画

- **夜航 · 山水月相**：月面融入水墨山水与湖景，主操作位于左侧。
- **月白 · 纸上月痕**：暖纸色与海松绿，水墨山景和轻淡月面。
- **流萤 · 极光抱月**：蓝紫极光与居中操作；修正月心取样位置，消除顶部暗色错位。
- **玄石 · 月下岩境**：296px 左侧月景、右侧任务队列的独立布局；月亮大小和位置不随窗口高度漂移。
- 同一球面光照模型平滑呈现盈缺；用光照角度缓动消除接近满月时突然扩亮，月面半径和不透明度固定，无新增动态光圈。悬停或键盘聚焦只显示进度说明。
- 月相按当前已发现任务等权汇总，完成任务计为 100%，非字节进度；空队列的满月是装饰，扫描与密码验证按实际状态显示。任务状态立即更新，视觉过渡不会延迟完成。
- 隐藏皮肤、最小化、系统关闭动画或高对比度模式会停止或跳过动画。绘制分辨率有上限，动画仅随进度更新，不持续运行背景粒子。
- 修正皮肤切换后场景仍沿用上一套底图的问题，以及左右布局切换后列表列宽未及时重算的问题。
- 月相列表的选中、悬停和分隔线使用当前皮肤配色，修正月白选中行沿用深色背景而难以阅读的问题。

### 文档、架构与验证

- 中英文 README 以功能为先，用新外观的实际 WPF 控件截图替换功能原型图；末尾展示四套皮肤与生产渲染器生成的月相 GIF。截图和动图使用演示数据。
- 皮肤资源、公共控件与只读状态展示分层，解压核心不依赖皮肤；外观偏好使用独立的 `appearance.json`，损坏或未知皮肤回退到默认值，保存失败不阻塞即时切换。
- 保留设计探索源文件和原画，更新皮肤扩展说明及文档素材生成入口。
- 扩展 WPF 回归：六套资源契约和偏好恢复、运行与暂停时换肤、菜单收起、单文件状态语义、1024/1200/1440 布局、150% DPI、弹窗焦点、月相逐帧收尾与最小化停表。
- 临时测试目录内分别验证加密 7Z 文件和文件夹解压，覆盖 Unicode 路径、路径密码推断、运行中换肤、输出内容和源文件保留。
- 发布脚本按指定版本写入程序集版本，仍检查 .NET 自包含运行时、7-Zip 和许可文件后生成便携 ZIP。

### 下载与升级

下载 [Zxtract-1.1.0-win-x64.zip](https://github.com/ColonelDarcy2018/Zxtract/releases/download/v1.1.0/Zxtract-1.1.0-win-x64.zip)，退出旧版后完整解压并运行 `Zxtract.exe`。Windows x64 便携包已包含 .NET 和 7-Zip；请保留同目录的引擎及许可文件。旧版密码库继续使用，外观偏好独立保存。使用资源管理器右键菜单或快捷方式时，将入口更新为新版路径。

包未代码签名。下载同一 Release 中的 `.zip.sha256`，用 `Get-FileHash .\Zxtract-1.1.0-win-x64.zip -Algorithm SHA256` 核对。

### 已知限制

应用界面当前为简体中文。月相是任务等权摘要，不能用来估算剩余时间。月相皮肤中的“仅扫描”使用 `Ctrl+S`。同一窗口先加入普通文件任务、再扫描包含它的目录时，原有路径去重可能复用普通任务，导致文件夹列表缺少对应树任务；本版未改变该逻辑，遇到此情况可在新窗口直接使用文件夹模式。

## English

Changes since the published v1.0.2 release; the crash fix and list/search improvements already shipped in 1.0.2 are not new in this version.

### Features and workflow

- Six built-in skins: Ink Flow, Clear Light, Night Voyage, Paper, Aurora and Stone. Switch instantly with a remembered preference; the main window, password assistant, menus, logs and panels update together.
- Appearance and version information live behind the gear beside minimize. Choosing a skin dismisses the menu and preserves running work, queue and selection.
- Moon-scene workbenches integrate tabs, status and actions into the painting, removing redundant focused-task, batch-state and settings bars. Ink Flow and Clear Light retain their original composition.
- Two-line extraction settings summaries and a centered options dialog, read-only during active/paused runs, editable while idle, with Escape and focus restoration.
- Real per-file percentages, thin progress bars and lightweight activity indicators. Password checks, staging and output commit do not fabricate percentages; existing retry, open-location and menu commands are reused.
- Pause/resume labels explicitly describe scheduling: active extractions continue while new jobs wait.

### Scenes and motion

- Night Voyage: mountain lake and ink-painted moon with left-side primary actions.
- Paper: warm paper, green accents and an ink landscape with a pale moon.
- Aurora: violet-blue curtains and centered actions; corrected lunar texture alignment removes the dark upper cap.
- Stone: a dedicated 296px scenic rail beside the task queue, with fixed moon size and placement across window heights.
- A consistent spherical-lighting renderer with eased light-angle transitions removes the sudden final expansion near full moon. Disk radius and alpha remain fixed, without an added animated halo; hover/focus only reveals details.
- Moon progress equally weights discovered tasks, not bytes. Completed tasks contribute 100%; idle full moons are decorative, and scanning/password checks keep truthful semantics. Visual easing does not delay task completion.
- Hidden, minimized, reduced-motion and high-contrast surfaces stop or skip motion. Raster resolution is bounded; progress-driven animation does not run perpetual background particles.
- Fixed stale artwork after skin changes and cached column widths after switching compositions.
- Row selection, hover and separators follow the active palette, keeping selected rows readable in the light Paper skin.

### Documentation, architecture and verification

- English and Chinese READMEs put features first, illustrated with the shipping WPF controls. A closing gallery and production-rendered GIF introduce the new skins. All screenshot data and replay progress are samples.
- Separate palette resources, shared controls and a read-only status presenter keep skins independent of extraction. Appearance has its own settings file with corruption/unknown-ID fallback and non-blocking save failures.
- Retained design explorations and artwork; updated extension documentation and added reproducible documentation rendering.
- Expanded WPF checks cover all six palettes, preferences, running/paused switching, menu dismissal, row semantics, 1024/1200/1440 layouts, 150% DPI, modal focus, final-phase continuity and inactive/minimized shutdown.
- Encrypted 7Z file/folder integration checks in temporary fixtures cover Unicode paths, inferred passwords, switching during extraction, output content and source retention.
- Packaging now writes the requested assembly version and still validates the runtime, 7-Zip and licenses before creating the portable ZIP.

### Download and upgrade

Download [Zxtract-1.1.0-win-x64.zip](https://github.com/ColonelDarcy2018/Zxtract/releases/download/v1.1.0/Zxtract-1.1.0-win-x64.zip), exit the old application and extract the complete package. It includes .NET and 7-Zip for Windows x64. Keep engine and license files alongside the executable; existing password settings remain compatible. Update shortcuts or re-register Explorer menus for the new path. Verify the ZIP against the accompanying `.zip.sha256` asset. The package is not code-signed.

### Known limitations

The application interface is currently Simplified Chinese. Moon progress cannot estimate remaining time. Use `Ctrl+S` for scan-only in moon-scene skins. Adding an archive as a file task and then scanning its folder in the same window can reuse the existing ordinary task through path deduplication and omit its tree row. This existing behavior is unchanged; use folder mode in a fresh window if affected.
