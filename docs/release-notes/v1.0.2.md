# Zxtract 1.0.2

文件夹解压闪退修复与界面调整 / Folder-extraction crash fix and UI improvements.

## 中文说明

### 修复与改进

- 修复任务行创建时，进度条向只读属性回写导致应用闪退的问题。文件和文件夹模式的进度绑定均使用单向绑定。
- 顶部显示整体运行状态，底部显示任务汇总；密码验证细节归到对应任务，不再用“密码尝试 1/1”覆盖全局状态。
- 对齐文件列表与表头，统一列间距、行高和操作区；解压时显示百分比与进度条，并区分等待、运行、完成和失败状态。
- 增加按钮悬停、按下和键盘焦点反馈，强化选中行和筛选项的显示；复制路径后短暂显示“已复制”。
- 避免进度更新反复重建列表，修复重复任务行，并保留仍在当前筛选范围内的选中项。
- 增加搜索占位提示、清除按钮和分类空状态；密码与更多选项面板互斥展开，文件冲突策略改为中文说明。
- 中英文 README 分开呈现，并提供语言切换入口。
- 增加实际 WPF 任务模板及布局回归检查，覆盖进度、暂停、筛选、搜索、选中项和面板切换。

### 下载与升级

- 下载 [Zxtract-1.0.2-win-x64.zip](https://github.com/ColonelDarcy2018/Zxtract/releases/download/v1.0.2/Zxtract-1.0.2-win-x64.zip)。这是 Windows x64 便携包，已包含 .NET 运行时和 7-Zip 引擎，无需单独安装 .NET。
- 退出旧版，将新版完整解压到一个目录，运行 `Zxtract.exe`。请保留同目录的 `7z.exe`、`7z.dll` 和许可文件，不要只复制主程序。
- 如果使用资源管理器右键菜单，请从新版应用重新注册菜单，使入口指向新版程序；开始菜单或自建快捷方式也应指向新版路径。
- 正式包尚未代码签名。可下载同一 Release 的 `Zxtract-1.0.2-win-x64.zip.sha256`，使用 `Get-FileHash .\Zxtract-1.0.2-win-x64.zip -Algorithm SHA256` 核对完整性。

## English

### Fixes and improvements

- Fixed a crash when WPF task rows were created: the progress bar attempted to write back to a read-only property. File and folder progress now use one-way bindings.
- Separated session status and task totals from per-task password verification details, removing the misleading global “password attempt 1/1” message.
- Aligned task columns with their headers and standardized spacing, row height and actions. Extraction shows a percentage and progress bar, with distinct waiting, running, completed and failed states.
- Added clearer hover, pressed and keyboard-focus feedback, row/filter selection styling and temporary confirmation after copying paths.
- Avoided rebuilding the task list on routine progress updates, fixed duplicate rows and preserved selections that remain in the active filter.
- Added search hints, a clear button and contextual empty states. Password/options panels open one at a time, and conflict policies have readable Chinese labels.
- Split the English and Chinese READMEs with quick language-switch links.
- Added regression checks using the actual WPF task template and layout for progress, pause, filtering, search, selection and panel switching.

### Download and upgrade

- Download [Zxtract-1.0.2-win-x64.zip](https://github.com/ColonelDarcy2018/Zxtract/releases/download/v1.0.2/Zxtract-1.0.2-win-x64.zip). The Windows x64 portable package includes the .NET runtime and 7-Zip engine; no separate .NET installation is needed.
- Exit the previous version, extract the complete package and run `Zxtract.exe`. Keep `7z.exe`, `7z.dll` and the license files alongside it.
- Re-register Explorer context menus from the new application and update any shortcuts to the new executable path.
- The package is not code-signed. Compare `Get-FileHash .\Zxtract-1.0.2-win-x64.zip -Algorithm SHA256` with the accompanying `Zxtract-1.0.2-win-x64.zip.sha256` asset.
