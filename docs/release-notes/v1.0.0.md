# Zxtract 1.0.0

首个正式版本，聚焦“可靠地处理复杂压缩文件集合”。

## 主要能力

- 普通单文件/多文件解压和文件夹批量扫描。
- 7z 分卷、RAR 分卷识别与跨目录归并。
- 嵌套压缩包递归解压、轮次限制和循环检测。
- 多候选密码、路径推断、自定义推断规则和本地密码库。
- 失败、取消、密码错误、缺少分卷任务的路径复用与快速重试。
- 暂停/继续、日志查看、冲突处理和成功后删除源文件选项。
- Zxtract 品牌图标、紧凑窗口布局和双模式 Tab 界面。
- 可编辑 OpenPencil 设计稿与可复现的同步脚本。

## 构建信息

- Target framework: .NET 8 / WPF
- Runtime: Windows x64
- Archive engine: bundled 7-Zip binaries
- Version: `1.0.0`

## 已知说明

OpenPencil 0.15.1 在 Windows 上偶尔会出现保存请求卡住。项目内已保留 `.fig` 设计源文件和 JSX 重建脚本；编辑设计稿后建议先确认 OpenPencil 保存成功，再同步更新 `design/openpencil/Zxtract.fig`。
