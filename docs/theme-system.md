# 皮肤与界面架构

## 使用

主窗口右上角齿轮按钮中的「外观」选择器提供：

- **墨流 · 深色**：默认皮肤，深色工作台、青绿/蓝紫进度条、右上角水墨纹理。
- **清简 · 浅色**：使用相同布局与交互，适合明亮环境。
- **夜航 · 山水月相**：将当前任务的真实状态映射到无光晕水墨山水中的月相；月亮只在任务进度变化时平滑过渡，悬停或键盘聚焦只显示说明，不改变画面。
- **月白 · 纸上月痕**：暖纸色水墨山景，浅色月面与海松绿控件。
- **流萤 · 极光抱月**：蓝紫极光、独立月面纹理和居中操作区。
- **玄石 · 月下岩境**：296px 左侧月景、右侧列表的独立布局，月面直径 103px、顶部距场景 85px。

切换立即生效，选择后外观菜单自动关闭，无需重启，不会重新创建任务队列、修改密码候选或取消任务。密码助手、选项、日志、下拉菜单和窗口标题栏同步更新；标题栏颜色取决于 Windows 对 DWM 深色标题栏的支持。玄石通过重排同一套控件实现左右布局，切回其它皮肤恢复各自布局并重算列表列宽。

偏好单独保存在 `%LOCALAPPDATA%\Zxtract\appearance.json`，不与密码库混用。缺失、损坏或已不存在的皮肤 ID 会回退到墨流。无法保存偏好时，当前窗口仍可换肤，选择器提示说明保存失败。

皮肤设置、关于版本和密码收进弹出面板。夜航的解压选项使用 530px 居中遮罩弹窗，运行或暂停期间只读，空闲时直接绑定原有设置；Escape 关闭后把焦点还给入口。夜航主界面按已确认的完整设计排版：42px 标题栏、350px 山水区、顶部页签、左侧状态和操作、背景底部两行设置摘要、36px 列表留白与 60px 紧凑任务行。重复的右侧聚焦栏、批次条和外置设置工具栏不再显示。墨流和清简继续使用原布局。

夜航皮肤的状态区只有一个主状态层：`LunarStatusPresenter` 只读观察当前工作流任务，不参与调度。已完成任务计为 100%，运行中的任务使用实际解压百分比，密码验证/扫描等无法计量的阶段不制造假进度。月相提示中明确“按当前已发现任务等权汇总，非字节进度”。

## 分层

```text
Themes/InkFlow.xaml / ClearLight.xaml   皮肤资源：颜色、渐变、纹理、签名
Themes/NightVoyage.xaml                 夜航资源与山水底图
Themes/LunarPaper.xaml / LunarAurora.xaml / LunarStone.xaml   另外三套月相配色与底图
Themes/NightLayout.xaml                 夜航专属页签、列表和交互模板
              ↓ DynamicResource
Themes/Controls.xaml                  通用控件模板与交互状态
              ↓
MainWindow / PasswordAssistantWindow   布局、数据绑定与命令入口
              ↓
MainViewModel / JobItemViewModel        解压状态与命令（不引用 Themes）
              ↓
ExtractUtil.Core                       扫描、密码解析、调度、解压与输出提交
```

`ThemeManager` 只替换应用资源字典中的当前皮肤字典，已加载的皮肤字典会缓存复用。公共控件模板、窗口实例、业务 ViewModel 与 `ICollectionView` 均保留。界面中的画刷必须使用 `DynamicResource`，不能在窗口内重新定义同名画刷，否则会遮蔽应用皮肤资源。

`Controls/TaskStateStrip.cs` 是纯展示组件：观察任务状态并绘制批次状态，不参与调度。小批次一项一格；大批次按可用像素宽度汇总，优先保留需处理状态。它不是整个批次的字节进度条。右侧百分比只属于选中的压缩包，验证密码等阶段不显示虚假的百分比。

`Controls/LunarScene.cs` 是纯展示控件：接收 `Progress`、`IsIndeterminate`、状态文本和详情文本，绘制夜航底图与月面。它不读取密码、不调用解压服务、不修改任务。动画只在实际进度变化时进行，根据光照角度跨度在 450–1700ms 内过渡；使用角度插值与两端速度、加速度均为零的缓动，避免接近满月时突然扩亮。不再于 94% 以后叠加整张满月图，而以同一光照模型连续回到原画。任务状态、文件行进度和悬停数据即时更新，动画不延迟业务完成。隐藏、最小化、减少动态或高对比度模式会停止或跳过动画。

`Controls/NightOptionsPanel.xaml` 仅负责设置弹窗的布局与绑定，不复制解压逻辑。`LunarStatusPresenter` 的两行摘要从实际设置生成，完整路径和整体月相进度通过提示查看。单文件解压时，任务行直接显示真实百分比与 3px 细进度条；密码验证、整理分卷及输出提交不显示假百分比。列表中的重试、打开位置及更多菜单仍调用原有命令。

`Controls/TaskActivityIndicator.cs` 是 14px 矢量转环，仅说明任务仍处于运行状态，不代表完成比例。以 24fps 更新，等待/完成/失败/取消、控件卸载、隐藏皮肤和窗口最小化时停表；遵守系统减少动态和高对比度设置。暂停调度不会冻结仍在实际运行的文件，其转环和进度仍照常更新。

## 增加皮肤

1. 复制 `Themes/InkFlow.xaml`，保留全部资源键，调整颜色、渐变、纹理与签名。
2. 在 `ThemeManager.AvailableThemes` 注册 `ThemeDefinition`：稳定 ID、显示名、资源路径与 `IsDark`；只有需要月相工作台的皮肤设置 `HasLunarScene=true`。
3. 使用 WPF `Resource` 收录新增图片（参见应用项目文件）。不要引用设计稿或用户电脑上的绝对路径。
4. 在运行中切换并验证主窗口、密码助手、下拉项、日志、悬停、按下、键盘焦点、禁用及选中状态。
5. 执行下面的回归测试。六套皮肤使用同一套资源键，切换前会验证资源契约。新增月相场景还需在 `LunarScene.LoadArtwork` 中注册原画、无月底图和实际月心/半径，并校验月面取样对齐。

不需要复制窗口或业务 ViewModel，也不需要修改解压服务。当前实现是内置资源皮肤，不会加载外部任意 XAML 插件；六套皮肤共用任务与解压逻辑，四套月相皮肤仅替换外观层和状态展示层。原图在 `Resources` 中以 WPF Resource 嵌入，切换时检查场景资源 ID，避免旧底图和新布局混用。

## 验证

```powershell
dotnet build tools/ExtractUtil.UiSmoke/ExtractUtil.UiSmoke.csproj -c Release -o .build-check/ink-ui
dotnet .build-check/ink-ui/ExtractUtil.UiSmoke.dll --preview .build-check/ink-previews
dotnet .build-check/ink-ui/ExtractUtil.UiSmoke.dll --integration
```

覆盖范围：

- 实际 WPF 模板的文件/文件夹进度绑定；保留只读进度属性的 `Mode=OneWay`。
- 六套皮肤的任务行进度绑定；月相界面 8 种阶段的百分比/进度条/活动指示语义；实际窗口中转环运行、提交阶段无百分比，以及完成、减少动态、最小化和隐藏皮肤后的动画停止。
- 月相从 0%、50%、90%、94%、99% 到满月的逐帧检查：半径与不透明度固定、单调收尾、最后四帧像素变化逐渐减小；实际窗口完成后平滑过渡并最终停在 100%。`--moon-preview <目录>` 可输出满月附近各阶段的对照图。
- 实际选择器绑定、运行中与暂停时换肤、选中项及队列/视图实例保持、密码助手已打开时换肤。
- 偏好恢复、缺失/损坏/未知配置回退、写入失败时仍可切换，六套皮肤资源键一致。
- 玄石 1024/1200/1440 布局、103px 固定月面、唯一共享列表、切回夜航恢复布局；实际打开外观弹窗后切换四套月相皮肤，验证自动关闭、原画 ID 和运行任务保留。
- 夜航 1200×820 / 1024×720 / 1024×950 客户区、150% DPI；断言页签、主操作、列表的坐标、留白及行高；验证居中弹窗宽度、运行时只读、空闲设置绑定、键盘焦点与 Escape 返回。保留月相真实进度过渡、悬停不重绘、最小化停表和弹窗独占检查。
- 1200×730 / 1024×610 客户区布局及 150% DPI 渲染，展开密码/选项，搜索空态、筛选、右侧固定操作和可见进度条、日志面板皮肤；WPF 绑定警告检查。
- 临时目录内创建加密 7Z，在独立窗口中分别执行真实文件和文件夹解压，并在运行期间切换皮肤。验证路径密码推断、输出内容和源文件保留。测试不修改用户的真实压缩包或密码库偏好。

文档中的新皮肤图片由实际 WPF 控件配合测试任务渲染，不是 HTML 设计稿，也不代表用户真实文件。

`ExtractUtil.UiSmoke --docs <目录>` 生成六套皮肤、功能截图与 `animation-frames`，所有路径和密码条目是内存演示数据，不写入用户密码库。月相帧使用生产绘制与同一缓动函数；用 [文档动图脚本](../tools/Build-ReadmeMotion.py) 合成为 GIF。README 的动画是受控进度回放，不代表实际耗时。

### 现有问题（不属于皮肤改造）

集成检查发现：在同一窗口中先把一个压缩包作为文件任务加入，再扫描包含它的文件夹，现有 `MainViewModel._jobsByKey` 会按相同路径复用普通文件任务，导致文件夹列表没有对应树任务。此行为来自原有任务去重逻辑，本轮没有修改；加密解压回归使用两个独立窗口分别验证两种工作流。
